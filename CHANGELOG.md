### Fixed

- Navigation no longer leads to 404s: `/leads`, `/clients`, `/events`, `/contracts`, `/finance` each render a shared `ComingSoon` placeholder until their module is built, so every nav link and Dashboard metric card resolves to a real page
- `LeadDetailView`'s refetch-after-mutation no longer flashes a full loading skeleton, which was unmounting `LeadActions` before its success/error feedback (e.g. "Welcome Guide marked as sent.") ever became visible — found via browser smoke testing
- Event dates throughout the Events UI (`EventListTable`, `EventListCards`, `EventDetailPlaceholder`) were rendering one day early in timezones behind UTC — `new Date("2026-07-17")` parses a date-only string as UTC midnight, so `.toLocaleDateString()` in a negative-offset timezone showed July 16. Fixed with a new `formatEventDate()` helper (`modules/events/dateFormat.ts`) that constructs the `Date` from local year/month/day components instead. Found via browser smoke testing — confirmed the bug affected every seeded Event's displayed date, not just newly created ones, and that the fix corrected all of them at once.
